How to Assign a Task — A Complete Manual

Every field, every step, in plain language. Written to answer the question Rajesh Bohra raised: why an executive can’t finish a task that has no checklist — and exactly what to do about it.
A quick note on the word “your”: it means the one shared MCA Dashboard — the same system Rajesh, Dharmesh, every Director, every Manager and every Executive all log into. It is never one specific person’s private account.
The one rule that matters most
If a task has no checklist, the person it’s assigned to has nothing to click — no button, no tick box, nothing.

It doesn’t matter if the task is overdue or the work is finished in real life. The dashboard has no "Mark complete" button anywhere for a plain team member. The only way they can show progress is by ticking off checklist steps you gave them when you created the task. No checklist = no way for them to ever finish it themselves.

2How to assign a task — every step, in order

Walking through creating a real task: “File GSTR-1 for July”, a Monthly task for the General department, assigned to one person, with a 3-step checklist.

  1. Open Team › Goals (Tasks) and press the green + Add Task button, top right.
  2. Pick the tier. A row of buttons: Yearly / Half-Yearly / Quarterly / Monthly / Daily. For a monthly GST filing, pick Monthly.
  3. Type the Title. File GSTR-1 for July. This is required — the form will not save without one.
  4. Type a Description (optional). A one-line note on what "done" looks like, e.g. Reconcile sales register, file on the GST portal, save the ARN.
  5. Pick the Department. General. Required — a task with no department cannot be saved.
  6. Pick the Due date. The system shows you which financial quarter that date falls in, just so you can double check it’s right.
  7. Leave Status as Active (the default) unless the task is already finished or on hold.
  8. Build the Checklist. This is the step that was missed. Press Add checklist item and type each real step of the work, one per line:
    • Reconcile sales register
    • File on GST portal
    • Save the acknowledgement (ARN)
  9. Set how often each step repeats. Every checklist line has its own small dropdown: One-time (default, for a step done once), Daily, Weekly, Monthly, or Custom days (pick exact weekdays). For this filing, leave all three as One-time.
  10. Turn on “Report Work” only where you want it. See Section 4 below — it adds an extra safety step before a tick counts.
  11. Leave Progress alone. Once you’ve typed at least one checklist step, the Progress field locks itself and reads "Tracked automatically from the checklist above." You never touch it again — it moves on its own as ticks come in.
  12. Assign to members. Tick the person’s name — e.g. Priyanka Rasal. Required: a task with nobody assigned cannot be saved, and the system tells you so if you try.
  13. Press Add task. Done.

4What the assigned person actually sees

SituationWhat the executive sees on their screen
Task has no checklist Just a title, a description if you wrote one, and a static progress bar. No checkbox, no button, nothing to press. They cannot mark it done, no matter how overdue it is.
Task has a checklist Each step shown as a tick box, under the heading "Your checklist." Ticking a box completes that step for them personally. The task’s overall % updates the moment they tick.
A step has "Report Work" turned on That step is locked with a small padlock, labelled "Report to tick." They must first write a short note about what they did that day; only then does the tick unlock. If they try to tick first, the screen tells them: "Report your work first, then tick this task complete."
A step repeats (Daily / Weekly / Custom) It shows a small clock badge, e.g. "Daily" or "Mon · Wed · Fri." It resets to un-ticked at the start of each new day/week/month, so the same step can be completed again and again over time.
The due date has passed The checklist freezes with the message "Checklist closed. The due date has passed." Nobody can tick anything on it anymore — another reason to double-check the due date is realistic when you assign it.
The "Progress" trap A task with no checklist can still show a progress number — e.g. one of your live tasks currently reads 20%. That number was simply typed once by whoever created it. It is not a measurement of real work, it will never move on its own, and the assignee has no way to change it either. Only a checklist gives you a progress number you can actually trust.

6Common problems, and the real cause

What you're seeingWhy, and what to do
"The task is overdue and nobody has marked it done." It almost certainly has no checklist. Open the task, add at least one checklist step, save. The assignee will now have something to tick.
"The progress bar says 20% and never changes." No checklist exists, so that number was typed once by hand and is frozen. Add a checklist to get a real, moving percentage.
"I can’t save the task." You’re missing one of the two things every task needs: a Department and at least one assigned person. The screen names exactly which one is missing.
"The executive says they can’t tick a step." Check whether Report Work is on for that step — they need to submit a short work note first. Or the due date may already have passed, which freezes the whole checklist.
"I don’t see certain people to assign." A Manager only sees their own team plus themselves. A person also has to belong to the task’s department — either as their main one or as an extra one on their profile (Team › Manage › Multi department).
